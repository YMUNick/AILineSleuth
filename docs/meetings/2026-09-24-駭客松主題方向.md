## 一句話結論

選「製造業」主題，做 **給東南亞/台灣中小代工廠夜班主管的異常調查 Copilot**：Gemini 用固定查詢函式在 BigQuery 找證據、推出根因並產工單，把停線調查從 40 分鐘縮到 90 秒，每個結論都查得到證據。

## 共識

- 六人一致選點子 A（工廠異常 Copilot），B（小電商補貨）因模擬預測資料易被看穿而放棄，C（反詐騙客服）僅作備案。
- **定位**：鎖定大廠（Siemens Industrial Copilot、Cognite、Google MDE）顧不到、資料還在 Excel / PLC CSV 的中小代工廠，搭「中國+1」產能南移的 JAPAC 故事。
- **技術架構**：Cloud Run 單一服務（前後端）、BigQuery（模擬資料＋工單表）、Vertex AI Gemini function calling ＋ 約 5 個固定查詢函式（不讓 LLM 自寫 SQL、temperature 0）、Secret Manager、Cloud Logging、預算警示。砍掉 Vertex AI Search（SOP 直接放 prompt）與 ADK。
- **MVP 做**：一個異常劇本、三畫面、證據卡可回查 BigQuery 原始列、英文工單（評審掃 QR code 在手機開啟）。
- **MVP 不做**：多產線、真實 PLC 串接、預測、越南文（僅 roadmap 示意圖）、登入權限。
- **Demo 分鏡（90 秒五格）**：03:00 Line 2 亮紅燈 → 按 Investigate → 證據卡時間軸 → 結論＋信心標籤 → 掃 QR 開工單，字幕「40 min → 90 sec」。另主動 demo 一次「Insufficient evidence」灰卡作為信任賣點。英文介面、深色底琥珀警示、Inter 字體、2D 靜態 SVG 產線圖。
- **Pitch 三句**：開場「凌晨 3 點 Line 2 停線，每小時燒掉 X 萬，主管花 40 分鐘翻 Excel」；差異化「Siemens 賣有 MES 的大廠，我們服務資料在 Excel 的中小代工廠，按產線月付」；收尾「40 分鐘變 90 秒，每個結論都查得到證據」。
- **品質**：10 題已知根因回歸集（含 3 干擾項）≥9/10 才上線；證據數字可回查原始列。
- **商業模式**：導入費 ＋ 每產線月訂閱。
- **里程碑**：
  - 10/1：確定隊友、GCP 開通、2–3 場訪談、分鏡劇本（停損點）
  - 10/8：模擬資料＋固定查詢函式＋10 題回歸集
  - 10/10：Agent 串通檢查點
  - 10/13：Agent ＋三畫面串通
  - 10/16：部署、回歸 ≥9/10、錄備援影片
  - 10/17：繳交（留一天緩衝）

## 錢的問題

- 預估成本：GCP（BigQuery、Cloud Run）可能落在免費額度／新帳號贈金內——**待確認**；Gemini token 費用——**待估算**；老闆工時 60–80 小時（Eddie 估）× 時薪——**待估算**。
- 需要資金：GCP 現金上限——**待估算**（老闆拍板）；預算警示 50%／90%／100%（只通知不停止，需搭配速率限制與快取）。
- 回本時間：比賽本身不視為賺錢機會，獎金期望值以 0 計；商業化回本時間——**待估算**（需訪談數字）。
- Pitch 中的停線損失「X 萬」必須來自受訪者真實數字，沒問到一律標「待驗證」。

## 主要風險

1. **組隊資格**：規定 2–4 人，目前是一人公司；找不到合格隊友無法參賽。
2. **單人開發**：60–80 小時需每週約 25 小時投入，生病或卡關無人接手。
3. **LLM 不穩定／幻覺**：根因判錯會「一鍵放大錯誤」；需固定查詢函式、回歸集、證據可回查。
4. **現場 demo 翻車**：新加坡網路、冷啟動、延遲；需備援錄影、min-instances=1、逾時與快取。
5. **競品質疑**：評審會問「跟 Siemens 差在哪」，需訪談原話與數字支撐差異化。
6. **費用失控**：公開網址被濫用或反覆重跑；需預算警示＋速率限制。
