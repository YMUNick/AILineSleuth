### 10/10（六）停損點 ②：Agent 串通檢查

檢查標準：主線劇本從按下 Investigate 到出結論，Gemini 即時呼叫固定函式，結果正確。

**沒串通時的退路（採 Quinn 底線）**：
- **固定**：資料集只保留主線異常＋正常兩個情境，UI 縮成最小可 demo 的版本（例如產線圖只畫 Line 2）。證據卡回查原始列（F4）和灰卡（F6）是信任賣點，不能砍。
- **不能固定**：BigQuery 查詢和 Gemini 推論必須即時執行，**不退回全寫死劇本**。
- **理由**：官網要求「部署在 Google Cloud 的可運作原型」，全寫死可能被判定不符規定，導致整份作品失格，這個風險比 demo 不夠流暢大得多；而且我們的核心賣點是「每個結論都查得到證據」，寫死就等於自打嘴巴。Eddie 擔心的穩定性問題，改用「逐步驟快取＋標示 cached＋備援錄影」處理。
- 如果 10/10 連縮小範圍的即時版本都跑不動 → 老闆當天決定是否退出，不要拖到 10/16。
